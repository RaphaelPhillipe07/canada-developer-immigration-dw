# Scripts de apoio não avaliáveis

Esta pasta reúne scripts usados para gerar ou revisar artefatos do projeto. Eles são mantidos apenas para reprodutibilidade e **não fazem parte do material a ser avaliado pelo professor**.

Os entregáveis avaliáveis estão em `docs/`, `sql/` e, quando enviado pela equipe, `presentation/`. Os scripts desta pasta geram EDA, DOCX, diagrama dimensional e guia de preparação.
