# Ativar a apresentação no GitHub Pages

A branch `apresentacao` contém:

- `/apresentacao`: fonte React, estilos, testes e roteiro;
- `/docs`: build estático pronto para servir;
- `/docs/entrega-1.html`: página anterior preservada.

O site atual do repositório usa `main /docs`. Para servir a nova apresentação:

1. O proprietário ou um administrador abre Settings → Pages.
2. Em Build and deployment, mantém Deploy from a branch.
3. Seleciona a branch `apresentacao` e a pasta `/docs`.
4. Salva e aguarda a publicação.
